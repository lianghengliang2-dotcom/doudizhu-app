# 斗地主记分 APP - 真机运行指南

## 项目位置

将 `doudizhu_app` 文件夹复制到你电脑上，例如 `D:\doudizhu_app`

---

## 一、环境准备（首次使用）

### 1. 安装 Flutter SDK

1. 访问 https://docs.flutter.dev/get-started/install/windows/mobile
2. 下载 Flutter SDK 压缩包
3. 解压到 `C:\flutter`（路径不要有中文和空格）
4. 添加环境变量：
   - 打开「设置」→「系统」→「关于」→「高级系统设置」→「环境变量」
   - 在「用户变量」的 `Path` 中添加 `C:\flutter\bin`
5. 打开新的 PowerShell/CMD，验证：
   ```
   flutter doctor
   ```

### 2. 安装 Android Studio（Android 真机需要）

1. 下载安装 https://developer.android.com/studio
2. 打开 Android Studio → More Actions → SDK Manager
3. 安装 Android SDK（建议 API 34+）
4. 勾选「Android SDK Command-line Tools」

### 3. 安装 Xcode（iOS 真机需要，仅 Mac）

> iOS 真机测试需要 Mac 电脑 + Xcode。Windows 无法直接运行 iOS 应用。
>
> 如果没有 Mac，可以用 Android 真机测试。

---

## 二、Android 真机运行

### 1. 手机设置

1. 打开「设置」→「关于手机」→ 连续点击「版本号」7 次，开启开发者模式
2. 打开「设置」→「系统」→「开发者选项」
3. 开启「USB 调试」
4. 用数据线连接电脑，手机上弹窗点「允许」

### 2. 运行

打开 PowerShell，执行：

```powershell
cd D:\doudizhu_app
flutter pub get
flutter devices
```

确认看到你的手机设备后：

```powershell
flutter run
```

APP 会直接安装并启动在你手机上。

### 3. 热重载

运行中修改代码后：
- 按 `r` → 热重载（保持状态）
- 按 `R` → 热重启（重置状态）
- 按 `q` → 退出

---

## 三、iOS 真机运行（需要 Mac）

### 1. 前置条件

- MacBook / iMac / Mac mini
- Xcode（App Store 下载）
- Apple ID（免费账号即可）

### 2. 手机设置

1. 用数据线连接 iPhone 到 Mac
2. iPhone 上弹窗点「信任此电脑」
3. Xcode → Preferences → Accounts → 添加你的 Apple ID

### 3. 配置签名

```bash
cd D:\doudizhu_app
open ios/Runner.xcworkspace
```

在 Xcode 中：
1. 选择「Runner」项目
2. Signing & Capabilities → Team 选择你的 Apple ID
3. Bundle Identifier 改为唯一值，如 `com.yourname.doudizhu`

### 4. 运行

```bash
flutter pub get
flutter run
```

> 首次安装可能需要在 iPhone 上信任开发者：设置 → 通用 → VPN与设备管理 → 信任你的开发者账号

## 四、打包 APK（Android，无需连电脑）

如果不想连接电脑调试，可以直接打包 APK：

```powershell
cd D:\doudizhu_app
flutter build apk --release
```

打包完成后，APK 文件在：
```
build\app\outputs\flutter-apk\app-release.apk
```

把这个文件传到安卓手机，直接安装即可。

## 五、常见问题

### flutter doctor 报错

按提示逐项修复，常见问题：
- Android licenses 未接受：运行 `flutter doctor --android-licenses`，一路按 `y`
- Android SDK 路径未设置：运行 `flutter config --android-sdk <SDK路径>`

### 手机连接后 flutter devices 看不到

1. 确认 USB 调试已开启
2. 尝试换数据线（有些线只能充电）
3. 重新插拔数据线
4. 手机上重新允许 USB 调试授权

### pub get 失败

使用中国镜像，在 PowerShell 中执行：

```powershell
$env:PUB_HOSTED_URL="https://pub.flutter-io.cn"
$env:FLUTTER_STORAGE_BASE_URL="https://storage.flutter-io.cn"
```

然后再运行 `flutter pub get`。

### iOS 打包

iOS 正式发布需要 Apple 开发者账号（$99/年）。测试阶段用免费 Apple ID 即可在真机运行。

## 六、将网页版安装到手机（PWA）

将 `doudizhu_app` 部署到支持 HTTPS 的网站后，用手机浏览器访问 `preview.html`。首次访问必须保持在线并使用 HTTPS，`file://` 地址不能安装 Service Worker，也不能完成离线安装。

### iPhone / iPad（Safari）

1. 在 iPhone 或 iPad 上使用 Safari 打开部署地址。
2. 点按浏览器的“分享”按钮，选择“添加到主屏幕”。
3. 确认名称后添加；以后从主屏幕打开，它会作为 Web App 运行。

### Android（Chrome）

1. 在 Android 手机上使用 Chrome 打开部署地址。
2. 打开浏览器菜单，选择“添加到主屏幕”或“安装应用”。
3. 确认安装后，从主屏幕启动应用。

## 七、离线验收与数据范围

首次在线打开完成后，开启飞行模式进行验收：确认应用可以打开；新建一局；录入并结算比分；撤销；查看历史；关闭应用；然后在仍离线的状态下重新打开。以上流程均应可用。

比分和对局数据只保存在当前手机的 `localStorage` 中，不会同步到其他手机、浏览器或账号。更换设备、清除浏览器数据或使用另一浏览器前，应自行做好需要的数据记录。

## 八、发布更新与缓存版本

`sw.js` 当前用规范化的 Service Worker scope 路径生成缓存前缀，并以 `const CACHE_NAME = CACHE_PREFIX + 'v1';` 声明版本。每次发布网页壳（HTML、CSS、JavaScript、图标或清单等）更新时，必须仅将版本后缀从 'v1' 到 'v2'，随后递增到 'v3' 等下一个版本；不要复用已发布的版本后缀。同源不同子目录会使用各自的缓存命名空间，不会在激活新版本时互删缓存。

安全更新流程是：恢复网络后重新打开页面或让页面回到前台，应用会在加载时、`online` 事件发生时，以及页面从后台恢复为可见时检查更新，并显示更新提示。用户选择“立即更新”后才激活新版本；若不选择，也可关闭所有仍在运行旧版本的页面，再重新打开以启用新版本。
