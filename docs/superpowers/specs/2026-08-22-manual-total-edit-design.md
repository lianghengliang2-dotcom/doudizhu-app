# 手动修改总分设计（网页版）

## 目标

在网页版 `preview.html` 的对局页顶部总分卡片上，允许玩家点击卡片、输入新总分来手动校正比分。只改总分，不改局记录。

## 范围

- 仅网页版 `preview.html`。
- 只修改 `session.totals[playerId]` 并持久化；不修改 `rounds`、不动历史、不改 schema。
- 不改 Flutter 版、不改计分公式、不改 PWA 其他行为。

## 交互

- 平时：每个总分卡片右上角显示小的 ✎ 编辑图标，提示可点击编辑。
- 点击卡片 → 该卡片进入编辑态：数字变为深色数字输入框（预填当前总分、自动聚焦并全选），下方出现「确定 / 取消」两个按钮。
- 确定（或按回车）→ 校验并保存；取消 → 恢复原显示。
- 编辑中点击另一张卡或空白处 → 取消当前编辑。
- 正分金 / 负分绿 / 零灰的颜色在重渲染时按新值自动更新。

## 数据流

- 保存：`session.totals[playerId] = newValue` → `persist()`（写 localStorage）→ `renderHomeSession()`。
- 重渲染时编辑态结束，卡片恢复普通显示。
- 局记录「最近三局 / 历史」保持不变，总分可能不再等于局记录之和（手动校正由用户负责）。

## 校验与错误处理

- 输入必须是整数，允许负数与零。
- 空值或非整数 → 提示「请输入整数」，输入框保留不关闭。
- 取消 / 点外部 → 丢弃修改，恢复原显示；不影响当前草稿（地主、胜负、加倍项等）。

## 实现要点（preview.html）

- 新增状态 `let editingScoreId = null;`。
- `renderHomeSession()` 生成 score-grid 时：若 `editingScoreId === id` 渲染编辑态（input + 确定/取消）；否则渲染普通卡片 + ✎ 提示。
- 渲染后若处于编辑态，对输入框 `focus()` 并 `select()`。
- 在 `#score-grid` 上用事件委托处理：点卡片 → 开始编辑；点确定 → 校验保存；点取消 → 结束编辑；编辑中点其他 → 取消。
- 新增少量 CSS：`.score-input`、`.score-actions`、`.score-edit-hint`。

## 测试与验收

- 内嵌 JS 用 `node --check` 语法校验。
- 整数/负数/空/非数字的校验逻辑用 Node 单测验证。
- 真机验收：点卡片改总分 → 数值与颜色更新；取消不生效；局记录不变；录下一局后总分在手动值基础上累加。
- 上线：更新 `preview.html`，同步递增 `sw.js` 缓存版本。
