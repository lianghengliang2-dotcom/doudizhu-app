# 局得分明细展示设计

## 目标

让进行中场次的“最近三局”和历史场次清楚显示每位玩家每局的实际得分变化，同时保持手机界面紧凑、现有计分规则与存储数据兼容。

## 范围

- 调整进行中首页的“最近三局”展示。
- 调整历史场次列表的总分摘要。
- 调整历史场次详情的逐局展示。
- 补充对应交互与渲染测试。

不修改计分公式、撤回逻辑、玩家数据、场次数据结构、localStorage schema、PWA 更新流程或 Service Worker 行为。

## 最近三局

- “最近三局”进入对局页面时默认展开。
- 标题按钮继续支持点击收起，再次点击重新展开，并同步维护 `aria-expanded` 与内容的 `hidden` 状态。
- 最多显示最近三局，按最新一局在前排列。
- 每局使用紧凑双行卡片：
  - 第一行显示 `第 N 局 · 玩家名地主 · 胜/负`。
  - 第二行按当前场次的玩家顺序显示三位玩家姓名与本局得分，例如 `张三 -10 · 李四 -10 · 王五 +20`。
- 正分必须带 `+`，负分保留 `-`，零分显示 `0`。
- 玩家姓名旁的圆点或强调线沿用该玩家的识别颜色；得分数字按正分、负分、零分使用现有的正向、负向、中性色，避免玩家颜色与得分含义冲突。
- 没有局记录时保持清晰的空状态，不显示伪造得分。

## 历史场次

### 历史列表

- 每个历史场次继续显示玩家姓名、结束时间和局数。
- 同一卡片增加三位玩家的最终总分摘要。
- 总分按历史场次保存的玩家快照顺序展示，正分带 `+`。
- 点击卡片仍进入该场次详情，不改变导航结构。

### 历史详情

- 顶部继续显示三位玩家的最终总分。
- “全部记录”中的每一局改用与“最近三局”相同的双行卡片。
- 每局显示地主、胜负以及三位玩家的姓名与得分变化。
- 历史详情按最新一局在前排列。

## 数据与兼容

- 局得分直接读取现有 `round.scores[playerId]`。
- 场次总分直接读取现有 `session.totals[playerId]`。
- 进行中场次的姓名和颜色来自当前玩家；历史场次使用 `session.players` 保存的玩家快照，避免后续改名影响旧记录。
- 如果旧记录缺少某位玩家的局得分或总分，该值按 `0` 展示，页面不得报错。
- 所有玩家姓名继续通过现有 HTML 转义函数输出。
- 不新增或迁移任何持久化字段。

## 布局与可访问性

- 得分明细允许换行，不能造成水平滚动。
- 双行卡片应适配 360、390、430 像素宽手机视口。
- 最近三局默认展开后允许页面自然纵向滚动；不再要求本局记分区域始终位于首屏。
- 收起/展开按钮保持键盘可操作，并提供正确的 `aria-expanded` 和 `aria-controls`。

## 测试与验收

- 最近三局有记录时默认展开。
- 点击标题能够收起，再次点击能够展开。
- 最近三局每局显示三位玩家姓名、正确符号和正确得分，并保持场次玩家顺序。
- 历史列表显示每位玩家的最终总分。
- 历史详情的所有局显示三位玩家的逐局得分变化。
- 缺失得分字段时显示 `0` 且不抛出异常。
- 现有计分、撤回、持久化、历史快照和 PWA 测试全部通过。
- 在 360×800、390×844、430×932 视口验证无水平溢出，展开与历史导航交互正常。
